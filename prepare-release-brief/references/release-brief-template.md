# Release Brief Template

```text
Release:
Range inspected:
Version recommendation:

Highlights:

Fixes:

Breaking changes:

Upgrade notes:

Risk notes:

Verification:

Maintainer checklist:
- Version metadata updated
- Changelog updated
- Tests run
- Docs updated
- Release artifact/build checked
- Follow-up issues filed
```

## Commit Buckets

- `feat` -> Highlights or new features
- `fix` -> Fixes
- `docs` -> Documentation
- `test` -> Verification improvements
- `refactor` -> Internal changes unless public behavior changed
- `build`, `ci`, `deps` -> Maintainer notes or risk notes
- no conventional prefix -> classify by touched files and commit message
